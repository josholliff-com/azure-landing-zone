# Architecture Decision Records

Each record captures one decision: what forced it, what was considered, what was chosen, and what that choice costs. Records are never edited after acceptance and never renumbered. A reversed decision keeps its record and gains a superseded status, because the fact that the reasoning changed is itself worth keeping.

The [template](template.md) is the starting point for new records.
